## 修复: SVN diff 预览 JSP 文件 URL 错误

### 问题
双击预览 JSP 文件时, svn diff 报 E170013/E175013 错误, URL 中混入了 XML 属性:
```
http://10.0.8.16:8989/svn/ntss4%3Cpath%0D%0A...text-mods=%22true%22...%3E/trunk/...jsp
```

### 根因
`parse_log_xml` 中的正则 `<path[^>]*>` 会错误匹配 `<paths>` 包装标签:
- `<path` 是 `<paths>` 的前缀
- `[^>]*` 匹配了 `s`
- 导致捕获组包含内层 `<path text-mods="true" ...>` 的标签和属性

### 修复
正则改为 `<path(?:\s[^>]*)?>`:
- `<path` 后必须是空格(有属性)或直接 `>` (无属性)
- 不会匹配 `<paths>` (因为 `s` 既不是空格也不是 `>`)
